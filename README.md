# وب‌سایت شخصی و پورتفولیو (MSz)

این پروژه وب‌سایت شخصی من است. هدفش معرفی خودم، نمایش تجربیات و مهارت‌هایم و جایی برای انتشار مقالاتم است. کسی که می‌خواهد با کارهای من آشنا شود یا با من تماس بگیرد، همه چیز را در یک‌جا پیدا می‌کند.

> **وضعیت فعلی:** فرانت‌اند در حال ساخت است (ساختار پایه، نوار ناوبری، لوگو و حالت روز و شب آماده‌اند). بک‌اند هنوز شروع نشده و پوشه‌ی `server/` خالی است. محتوای صفحه‌ها فعلاً فقط عنوان دارد.

## بخش‌های سایت

| صفحه | آدرس | هدف |
| --- | --- | --- |
| معرفی | `/` | معرفی من و مسیر کاری‌ام |
| مقالات | `/articles` | مقاله‌هایی که می‌نویسم |
| مهارت‌ها | `/skills` | مهارت‌ها و تجربیات فنی من |
| ارتباط با من | `/contact` | راه‌های تماس با من |

## ویژگی‌ها

- صفحه‌ی فارسی و راست‌به‌چپ با فونت وزیرمتن (Vazirmatn)، ادامه‌ی رسمی فونت Vazir.
- نوار ناوبری ریسپانسیو: در دسکتاپ یک ردیف است و در موبایل به آیکون سه‌خط تبدیل می‌شود.
- حالت روز و شب که در مرورگر ذخیره می‌شود و روی همه‌ی المان‌ها اثر دارد.
- اندازه‌ی متن با عرض صفحه به‌تدریج بزرگ می‌شود.
- هر بخش صفحه‌ی جدا دارد.

## تکنولوژی‌ها

همه‌جا از TypeScript استفاده می‌شود.

- **فرانت‌اند:** React، Vite، Tailwind CSS نسخه ۴، React Router
- **بک‌اند (برنامه‌ریزی‌شده):** Node.js، Express و یک دیتابیس ساده‌ی فایل JSON

## ساختار پروژه

```
personal-website/
├── client/                 فرانت‌اند
│   ├── public/             فایل‌های ثابت (آیکون سایت)
│   ├── src/
│   │   ├── components/     اجزای مشترک (Navbar، Logo)
│   │   ├── hooks/          هوک‌ها (useTheme برای روز و شب)
│   │   ├── pages/          یک فایل برای هر صفحه
│   │   ├── App.tsx         مسیرها و چیدمان اصلی
│   │   ├── main.tsx        نقطه‌ی شروع برنامه
│   │   └── index.css       Tailwind، فونت و استایل پایه
│   ├── .env.example        نمونه‌ی تنظیمات محیطی
│   └── vite.config.ts      تنظیمات Vite، alias مسیر @/ و پروکسی /api
└── server/                 بک‌اند (هنوز خالی)
```

## اجرا روی سیستم خودتان

به Node.js نسخه‌ی ۲۰ یا بالاتر نیاز دارید.

```bash
cd client
cp .env.example .env
npm install
npm run dev
```

سایت روی `http://localhost:5173` باز می‌شود.

دستورهای دیگر داخل پوشه‌ی `client`:

| دستور | کار |
| --- | --- |
| `npm run build` | ساخت نسخه‌ی نهایی در پوشه‌ی `dist` |
| `npm run preview` | اجرای نسخه‌ی ساخته‌شده روی سیستم خودتان |
| `npm run lint` | بررسی کد با ESLint |

## تنظیمات محیطی

فایل `client/.env` را از روی `.env.example` بسازید. این فایل commit نمی‌شود. فقط متغیرهایی که با `VITE_` شروع می‌شوند در مرورگر دیده می‌شوند، پس هیچ رمز یا کلید محرمانه‌ای در آن نگذارید.
